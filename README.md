# حَصيف — منصة الحوكمة والامتثال

منصة سعودية لمتابعة تراخيص المنشآت وحوكمتها وامتثالها لنظام حماية البيانات الشخصية.
المواصفات الكاملة في [`docs/SPEC.md`](docs/SPEC.md) (الإصدار 1.1).

## التشغيل على جهازك (ماك)

**مرة واحدة فقط**، ثبّت:
1. [Docker Desktop](https://www.docker.com/products/docker-desktop/) وشغّله.
2. [Python 3.12+](https://www.python.org/downloads/).
3. [Node.js 20+](https://nodejs.org/).

ثم من تطبيق **Terminal**، داخل مجلد المشروع:

```bash
./scripts/dev.sh
```

يشغّل السكربت قاعدة البيانات، ويثبّت الحزم، ويشغّل الاختبارات، وينشئ بيانات تجريبية **ويطبع كلمات المرور**، ثم يفتح:

| | الرابط |
|---|---|
| واجهة العميل | http://localhost:3000 |
| لوحة الإدارة | http://localhost:3001 |
| توثيق واجهة الخادم | http://localhost:8000/docs |

حسابات التجربة: `ahmad@nukhba.example` (عميل)، `advisor@example.sa` (مستشار يخدم منشأتين)، `ops@haseef.sa` (فريق حصيف).

## البنية

```
apps/
  api/        FastAPI + Celery — الخادم ومحرك التنبيهات والذكاء الاصطناعي
    haseef/domain/    المنطق النقي (التنبيهات، المؤشر، حجب البيانات، العربية) — مختبر بالكامل
    haseef/services/  ربط المنطق بقاعدة البيانات
    haseef/ai/        مسار التدقيق والتحقق من مخرجات النموذج
    haseef/routers/   واجهات REST
  client/     Next.js — app.haseef.sa
  admin/      Next.js — admin.haseef.sa
packages/
  shared/     الأنواع، عميل الواجهة، الصياغة العربية، رموز التصميم
  brand/      الشعار (SVG)
db/
  migrations/ المخطط (PostgreSQL 16 + pgvector + RLS)
  tests/      اختبارات العزل بين المنشآت والعروض + فحص كل استعلامات الخادم
```

## الاختبارات

```bash
db/tests/run.sh                                   # العزل بين المنشآت (RLS) والعروض
python3 db/tests/sql_static_check.py apps/api     # كل استعلام في الخادم صالح مقابل المخطط
cd apps/api && .venv/bin/pytest                   # منطق التنبيهات، المؤشر، الحجب، التحقق من مخرجات النموذج
npm test -w @haseef/shared                        # الصياغة العربية في الواجهة
```

## حالة المرحلة 1

| الجزء | الحالة |
|---|---|
| مخطط قاعدة البيانات + RLS | ✅ مكتمل ومختبر على PostgreSQL فعلي |
| محرك التنبيهات (تخطيط وإرسال وإعادة محاولة) | ✅ المنطق مختبر؛ الاستعلامات مفحوصة |
| مؤشر حصافة | ✅ مختبر |
| حجب البيانات الشخصية | ✅ مختبر |
| التحقق من مخرجات الذكاء الاصطناعي | ✅ مختبر |
| واجهات الخادم (المصادقة، التراخيص، السياسات، الإدارة) | ✅ مكتوبة؛ أول تشغيل فعلي على جهازك |
| واجهة العميل: الدخول، الرادار، التراخيص | ✅ مكتوبة؛ التصميم معاين |
| لوحة الإدارة: نظرة عامة، المنشآت، التنبيهات، الاستهلاك | ✅ مكتوبة |
| ربط مزوّد واتساب فعلي | ⏳ المرحلة 3 (يحتاج حساب Unifonic/Meta واعتماد القوالب) |
| مزوّد الذكاء الاصطناعي داخل المملكة | ⏳ قرار مطلوب قبل المرحلة 2 |
| الحوكمة، سجل المعالجة، تقييم الأثر، مختبر العقود (شاشات) | ⏳ المرحلتان 2 و3 (الجداول جاهزة) |
