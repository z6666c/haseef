# قوالب واتساب للتقديم إلى Meta

سبعة قوالب من فئة **Utility** (رسائل خدمية لا ترويجية)، اللغة **Arabic (ar)**.
الأسماء والمتغيرات مطابقة لما يرسله الخادم (`apps/api/haseef/domain/alerts.py`):

| المتغير | المعنى | مثال |
|---|---|---|
| `{{1}}` | اسم المستلم | أحمد |
| `{{2}}` | اسم الوثيقة أو السياسة | رخصة بلدي — الفرع الرئيسي |
| `{{3}}` | اسم المنشأة | مؤسسة النخبة للمقاولات |
| `{{4}}` | العبارة الزمنية | خلال 7 أيام / اليوم / منذ يومين |
| `{{5}}` | التاريخ | 15/10/2026 |
| `{{6}}` | رابط الإجراء | https://app.haseef.sa |

قواعد Meta التي روعيت: لا يبدأ النص ولا ينتهي بمتغير، ولا متغيران متجاوران بلا نص بينهما، ولكل متغير مثال، ولا عبارات تسويقية.

## إعداد الويبهوك للبوت

- عنوان الويبهوك: `https://app.haseef.sa/api/v1/webhooks/whatsapp` مع الاشتراك في حقل `messages`.
- `HASEEF_META_VERIFY_TOKEN`: رمز تختاره وتكتبه نفسه في إعدادات Meta.
- `HASEEF_META_APP_SECRET`: سر التطبيق للتحقق من توقيع كل طلب (إلزامي في الإنتاج).

## خطوات التقديم

1. في **WhatsApp Manager** ← Message templates ← Create template.
2. اختر Category = **Utility**، والاسم كما هو أعلاه حرفياً، واللغة **Arabic**.
3. الصق نص الـ Body، ثم الـ Footer، وأدخل الأمثلة لكل متغير بالترتيب.
4. لا تضف أزراراً (الرابط داخل النص يكفي، والخادم يرسل 6 متغيرات للنص فقط، و7 لقالب الأقساط).
5. بعد الاعتماد: اضبط في الخادم `HASEEF_WHATSAPP_PROVIDER=meta` مع `HASEEF_META_PHONE_NUMBER_ID` و`HASEEF_META_ACCESS_TOKEN`
   (أو `unifonic` مع `HASEEF_UNIFONIC_APP_SID` و`HASEEF_UNIFONIC_SENDER` عند استخدام مزود محلي).

> إن رفضت Meta قالباً بسبب تصنيفه كترويجي، احذف عبارة «لتجنب الغرامات» وأبقِ النص إخبارياً بحتاً، ثم أعد التقديم.
